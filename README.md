# 🕷️ 4Leg Spider Robot Simulator

다관절 4족 보행 로봇(MG90S 서보 12개, 3D 프린트 PLA 부품)의 **조립 설명서 + 동작 시뮬레이터 + 부하 분석**을 한 화면에 합친 웹 앱입니다.

## 쓰는 법
- 저장소를 내려받아 `index.html` 을 크롬 등 브라우저로 열면 됩니다(설치·인터넷 연결 불필요).
- GitHub Pages 로 열려면 저장소 설정의 Pages 에서 `main` 브랜치 / 루트를 고르세요.

## 들어 있는 것
- 🔧 **조립 설명서** — 30단계. 서보 선 정리(1·4·7·10번 느슨한 고리 + C 가로대 홈, 선은 위로 둥글게), 선택 단계로 «미리 하는 납땜»·«네오픽셀 확장하기»(납땜 확인 → 브레드보드 금속 띠 → 연결판 W → 막대 → 선 연결 → 코드 켜 보기). 설명창은 ▾ 접기로 화면을 넓게 볼 수 있어요
- ⌨ **로봇 코드 실행** — MakeCode `Work(...)` / `basic.pause(...)` / `복귀()` 코드를 실행, 예제 음악 11곡, 내 코드 파일 추가, 동작 예시 버튼
- 🎵 **음악과 함께 재생** — 예제 곡 1~7번은 유튜브 음악에 맞춰 로봇이 춤춰요. 유튜브 재생 시간을 기준으로 맞추기 때문에 광고·버퍼링이 있어도 다시 맞춰요. 음원 파일은 저장소에 없고, 소리는 유튜브에서 나와요. 파일(더블클릭)로 열면 유튜브가 막으니 인터넷 주소로 여세요
- 🎚 **다리를 끌어 Work 만들기** — 3D 화면에서 다리를 끌거나 각도 상자에 숫자를 쓰면 `Work(...)` 한 줄이 만들어짐
- 📊 **물리 모드(Rapier)와 부하 분석** — 중력·마찰·넘어짐·무게중심, 서보별 토크 히트맵, 타임라인
- 코드 점검(모터별 합계 · 서보 범위 · 구간 경계선), **보정 Work 추가**
- 💡 **네오픽셀 8×1 막대 4개**(아랫다리) — `strip.showColor(...)` 색이 막대에 켜짐
- **GIF 저장** — 코드 동작을 GIF 로 저장(길면 최대 3개 파일로 나눔)
- 🧪 **과학 실험실** — 무게중심·중력·바닥 마찰·무게·경사면·짐 싣기 등 실험, 기록 남기기
- 개발자 모드 — 부품 편집·조립 도구

## 파일
- `index.html` — 앱 전체
- `three.min.js`, `OrbitControls.js`, `TransformControls.js` — 3D 화면(three.js r128)
- `rapier.js` — 물리엔진(Rapier 0.12, wasm 포함)
- `parts_data.js` — 3D 프린트 부품(STL) 데이터
- `부품변형_C.js` — 서보 선 홈이 있는 C 윗다리 변형(C1·C2) 데이터. 앞오른·뒤왼 다리는 C1, 앞왼·뒤오른 다리는 C2로 그려집니다 (홈이 아래로)
- `songs_data.js` — 예제 음악 코드 11곡
- `examples/` — 예제 음악 코드 원본(.txt)

이전 버전(단일 파일 시뮬레이터)은 태그 `old-simulator-2026-11-14` 에 남아 있습니다.
