# 🕷️ 4Leg Spider Robot Simulator

다관절 4족 보행 로봇(MG90S 서보 12개, 3D 프린트 PLA 부품)의 **조립 설명서 + 동작 시뮬레이터 + 부하 분석**을 한 화면에 합친 웹 앱입니다.

## 쓰는 법
- 저장소를 내려받아 `index.html` 을 크롬 등 브라우저로 열면 됩니다(설치·인터넷 연결 불필요).
- GitHub Pages 로 열려면 저장소 설정의 Pages 에서 `main` 브랜치 / 루트를 고르세요.
- 처음 열면 말풍선 안내 3개가 한 번 나와요. 다시 보려면 왼쪽 맨 아래 «처음 안내 다시 보기».

## 화면 구성
- **왼쪽 위 탭 3개** — 🔧 조립 · ⌨ 코딩 · 🔬 실험. 고른 탭에 필요한 것만 보여요(마지막에 고른 탭을 기억).
- **3D 화면 아래 재생 막대** — ▶ 처음부터 실행 · ⏸ 일시정지 · ■ 중지, 진행 막대(몇 번째 Work · 시간). 조립 탭에서는 숨어요.
- **코드 입력창 바로 아래**에도 ▶ 실행 · ■ 중지가 있어요. 입력창에서 **Ctrl+Enter** 로도 실행.
- 단추·칸에 마우스를 올리면 설명이 떠요.

## 🔧 조립 탭
- **조립 설명서** — 30단계. 개조식 안내(①②③ + 💡/⚠). 서보 선은 E·F·G·H 의 «선 걸이»로 정리, 선택 단계로 «미리 하는 납땜»·«네오픽셀 확장하기»(납땜 확인 → 브레드보드 금속 띠 → 연결판 W → 막대 → 선 연결 → 코드 켜 보기). 설명창은 ▾ 접기로 화면을 넓게 볼 수 있어요
- **조립 영상 보기** — 유튜브 조립 영상을 새 창으로

## ⌨ 코딩 탭
- **코드 실행** — MakeCode `Work(...)` / `basic.pause(...)` / `복귀()` 코드를 실행. 실행 중인 줄은 입력창에 노란 띠로 표시
- **코드 입력창** — 줄 번호, `Work`·`pause`·`복귀`·반복문·주석 색 구분. 하늘색 점선 = 모든 모터 합계가 0(처음 자세로 돌아온 곳, 마우스를 대면 설명)
- 입력창 옆 상태: Work 개수 · 대기 · 예상 실행시간 · «모든 모터 합계 0 👍 / ⚠ 합계 0 아님»
- **동작 예시** 15개, **예제 음악** 11곡, 내 코드 파일 추가(.txt)
- 🎵 **음악과 함께 재생** — 예제 곡 1~7번은 유튜브 음악에 맞춰 로봇이 춤춰요. 유튜브 재생 시간을 기준으로 맞추기 때문에 광고·버퍼링이 있어도 다시 맞춰요. 음원 파일은 저장소에 없고, 소리는 유튜브에서 나와요. 파일(더블클릭)로 열면 유튜브가 막으니 인터넷 주소로 여세요
- 🎚 **다리를 끌어 Work 만들기** — 3D 화면에서 다리를 끌면 `Work(...)` 한 줄이 만들어짐. 다리에 마우스를 올리면 그 다리의 각도 상자 3개가 떠서 숫자로 넣을 수도 있어요(위쪽 «각도 상자 모두»로 12개 전부). 실행을 ⏸ 멈춘 자세에서도 이어서 끌 수 있고, 만든 줄은 멈춘 곳 바로 뒤에 들어감
- **🛠 도구** — 자세 초기화 · **GIF 저장**(길면 최대 3개 파일로 나눔) · 입력 지우기 · 복귀() 추가 · **보정 Work 추가**
- **모터별 분석 자세히** — 모터별 합계 · 서보 범위 · 구간
- 💡 **네오픽셀 8×1 막대 4개**(아랫다리) — `strip.showColor(...)` 색이 막대에 켜짐

## 🔬 실험 탭
- **물리 모드(Rapier)** — 중력·마찰·넘어짐·무게중심. 물리 창은 기본 «간단히»(상태 · 기울기 · 가장 힘든 서보), «자세히 ▾»로 서보 12개 표·그래프
- **부하 분석** — 서보별 힘 히트맵, 타임라인. 부하 분석 설정 안에 위험선 · 서보 최대 힘 · 미끄럼 μ · **안전하게 줄이기**
- 🧪 **과학 실험실** — 무게중심·토크·중력·바닥 마찰·발끝 모양·무게·서보 고르기·관성·경사면·짐 싣기·에너지 실험, 결과를 표로 비교

## 색의 뜻
파랑 = 실행·주요 단추 · 보라 = 실험 · 초록 = 잘 됨(합계 0, 서 있음) · 주황 = 주의 · 빨강 = 위험(넘어짐, 힘이 모자람) · 노란 띠 = 지금 실행 중인 줄

개발자 모드(위쪽 단추) — 부품 편집·조립 도구

## 파일
- `index.html` — 앱 전체
- `three.min.js`, `OrbitControls.js`, `TransformControls.js` — 3D 화면(three.js r128)
- `rapier.js` — 물리엔진(Rapier 0.12, wasm 포함)
- `parts_data.js` — 3D 프린트 부품(STL) 데이터
- `songs_data.js` — 예제 음악 코드 11곡
- `examples/` — 예제 음악 코드 원본(.txt)

이전 버전(단일 파일 시뮬레이터)은 태그 `old-simulator-2026-11-14` 에 남아 있습니다.
